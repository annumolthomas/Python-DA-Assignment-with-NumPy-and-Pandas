# Python-DA-Assignment-with-NumPy-and-Pandas
It is an assignment where data analysis is done using NumPy and Pandas. In NumPy 1D and 2D NumPy arrays are created, slicing, inspecting and indexing operations were done. In Pandas, Series is created and indexing, slicing manipulation were done. A Panda Data Frame is created. Data Exploration and Manipulation operations were done.
